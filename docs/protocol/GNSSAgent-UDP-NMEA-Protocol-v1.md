# GNSSAgent UDP NMEA 输入协议 v1

## 1. UDP 地址

- 协议：IPv4 UDP
- 目标地址：CCU 的任意 IPv4 地址（默认监听 `0.0.0.0`）
- 目标端口：`29501`

服务默认监听所有 IPv4 接口，并接受本机或远端 IPv4 发送方的数据报。

UDP 与 TCP 可以使用相同端口号。`29501/UDP` 与 `29501/TCP` 互不冲突。

## 2. 数据格式

一个 UDP 数据报只发送一条完整 NMEA 语句。

```text
$GNRMC,...*HH\r\n
```

要求：

- 数据报内容为原始 NMEA 字节，不增加包头或长度字段。
- NMEA 必须以 `$` 开始。
- `*HH` 后可以没有换行符，也可以使用 LF 或 CRLF。
- 单个数据报最大 1024 字节，包含可选的换行符。
- 不得把一条 NMEA 拆成多个数据报。
- 不得在一个数据报中放入多条 NMEA。
- 不得添加 `\0` 结尾。
- 批准的 NMEA 语句类型为 `RMC`、`GGA`、`GLL`、`GSA`、`GSV`、`GST`、`ZDA`。

## 3. 发送规则

- 串口进程每读到一条完整 NMEA，立即发送一个 UDP 数据报。
- 使用同一个 UDP socket，按串口接收顺序发送。
- 不解析、不修改、不合并 NMEA 内容。
- 不等待 ACK，不重传，不发送心跳。
- 单次发送失败不得影响串口读取；继续发送后续 NMEA。

## 4. 长度说明

UDP 已包含数据报长度。发送方把 NMEA 字节数传给 `sendto()`，接收方通过 `recvfrom()` 的返回值直接得到本数据报的 NMEA 长度，因此不需要应用层长度字段。

## 5. 协议演进

`29501/UDP` 固定使用本文定义的原始 NMEA 格式。本文没有线内版本字段。以后如果增加时间戳、序号或其他包头，必须使用新的 UDP 端口，不能在 `29501/UDP` 上混用新旧格式。
